# 使用說明

「校」會協助修正繁體中文錯字，或將注音按鍵、注音符號還原成繁體中文，使用 Gemini 的 `gemini-flash-lite-latest` 模型。先完成 [安裝與首次設定](INSTALL.md)。v2.2.0 起的下載版已包含以下三種用途。舊版 2.1.5 只支援中文錯字校正。

v2.3.0 起的下載版包含浮動 spinner、補標點與排版。v2.2.0 沒有這批新增功能。

## 怎麼校正

先完成輸入或選取要處理的文字，再快速按下、放開**右側 Option 兩次**。左側 Option 不會觸發。

只有游標在可編輯的文字欄位，且符合其中一項時，才會開始：

- **已選取文字**：校正並替換選取的內容。
- **剛在同一欄位打字、還沒超過 2 秒**：校正游標所在段落。

畫面自動折行仍算同一段。按 Return 換行才分成不同段落。一次最多校正 10,000 字。

### 浮動校正提示

校正開始後，文字末端旁會顯示旋轉 spinner 與「校正中」。提示不會寫入文件，也不會取得鍵盤焦點。完成、失敗或取消時會停止動畫並自動消失。

若文字欄位無法提供精確文字位置，提示會改放在輸入框右上角。連輸入框位置也無法取得時，仍可查看選單列的旋轉動畫。

### 補標點與排版

同一個右側 Option 快捷鍵會在三種用途上套用補標點與排版。Gemini 只在句意明確時補標點，中文敘述使用全形標點。短標題、片語、條列項目不強制加句號，重複驚嘆號、問號與刪節號保留原有語氣。

本機參考 [中文文案排版指北](https://github.com/sparanoid/chinese-copywriting-guidelines)，整理中英文、中文與數字的間距，中文敘述的數字轉為半形，常見數字與單位之間加空格，`15%`、`90°` 保持相連。行首縮排、行尾空白與原有換行保留。

```text
輸入：今天用ChatGPT整理了3份資料明天再檢查一次
預期：今天用 ChatGPT 整理了 3 份資料，明天再檢查一次。
```

網址、電子郵件、版本號、英文識別字、行內程式碼與 Markdown 連結會以佔位符保護，回覆後補回原文。佔位符被改動時拒絕替換。純英文列、Markdown 程式碼區塊與縮排程式碼列保留原文。Markdown 結構標記不參與排版，連結文字也會原樣保留。程式碼建議使用 Markdown 程式碼區塊或行內反引號標示，讓保護範圍明確。

一般中文校正另比對數字序列，允許全形轉半形，數值或數字順序改變時拒絕替換。注音還原可依讀音產生數字，仍需確認結果。

補標點仍可能誤判斷句，結果有誤可按 `⌘Z` 復原。補標點、排版與浮動提示均收錄於 v2.3.0 起的下載版。

## 看懂選單列狀態

同一個位置依序切換：**校 → spinner → ✓ → 校**。

- **校**：目前沒有正在校正。
- **旋轉動畫**：正在等待或處理校正結果。
- **勾號**：校正已完成，約 1 秒後恢復「校」。原文沒有需要修改的錯字也會顯示勾號。
- **驚嘆號**：校正未完成，點開「校」選單可查看原因。提示會在開啟選單或下次校正時消失。

完成後直接替換文字。結果有誤可按 `⌘Z` 復原。等待時若繼續打字、點擊、捲動、移動游標或切換 App，會取消校正，旋轉動畫直接停止。

連按得太慢、長按 Option，或搭配其他按鍵時不會開始。

## 三種用途

以下三種輸入都以這句繁體中文為預期結果：

```text
這個輸入法的選字不太準，請幫我檢查錯字。
```

### 1. 中文錯字校正

```text
這個輸入法的選自不太準，請幫我檢查錯自。
```

### 2. 忘記切換輸入法的注音按鍵

在英文輸入狀態下，打出標準注音鍵盤按鍵：

```text
5k4ek7gj bj4z832k7vm03y41j6w945jp3<fu/31; ji3ru03t86hji4y4>
```

其中 `2k7` 是「的」的讀音，空格可表示第一聲結束，`<`、`>` 對應「，」「。」。

v2.5.1 起，本機先判斷是否有足夠注音按鍵特徵，再把原始按鍵與逐鍵轉出的注音一起送給 Gemini。至少需要三個音節、兩個聲調鍵及足夠的合理音節，但不要求每個音節合法；少量多打、漏打或誤按可由 Gemini 依完整讀音與上下文嘗試修復。本機不會先刪除或猜測錯誤按鍵。

模型不確定時保留原始按鍵，歷史會顯示「未能還原」，而非「無需修改」。若結果混有未還原的按鍵或注音，App 會拒絕替換。檔名、網址、明確程式碼及 Markdown 程式碼區塊優先保留。

短字串、缺少足夠注音特徵、混合中英文與其他鍵盤配置仍可能不進入按鍵還原；少量不完整音節不會直接擋掉整句。一般英文、網址及程式碼應保留。辨識與選字仍可能出錯，結果有誤時可按 `⌘Z` 復原。

### 3. 注音符號還原

```text
ㄓㄜˋㄍㄜ˙ㄕㄨㄖㄨˋㄈㄚˇㄉㄜ˙ㄒㄩㄢˇㄗˋㄅㄨˊㄊㄞˋㄓㄨㄣˇ，ㄑㄧㄥˇㄅㄤㄨㄛˇㄐㄧㄢˇㄔㄚˊㄘㄨㄛˋㄗˋ。
```

「輸」使用第一聲 `ㄕㄨ`，不加聲調符號。Gemini 依上下文選擇同音字，結果可能因語境與模型更新而不同。

## 選單功能

v2.5.0 的選單上方顯示「✓ 已就緒」或尚未完成的設定，以及最近一次處理的結果與耗時。未完成設定時，請先到「檢查與測試…」查看各項狀態。

- 「校正歷史…」：查看本次開啟 App 後的最近 20 筆，包含時間、使用的 App、耗時、原文與結果。沒有成功還原的注音按鍵會顯示「未能還原」。修改的字、標點與空格會標示；長文字使用變更範圍標示。取消或失敗的紀錄不會把模型結果當作已成功替換，請依原因檢查目前文字。可選取紀錄後複製結果，也可清除全部歷史。歷史不寫入檔案，關閉 App 即清除。
- 「檢查與測試…」：顯示金鑰、輔助使用、輸入監控與快捷鍵四項狀態，以及安裝位置、最近處理步驟與 Gemini 測試結果。
- 「設定 Gemini 金鑰…」：貼上或更新金鑰。已設定只代表本機有儲存金鑰，能否使用由實際校正或 Gemini 測試確認。
- 「權限設定」：子選單分別開啟輔助使用與輸入監控設定。請加入實際安裝位置的 App，預設為 `/Applications/GeminiParagraphCorrection.app`。
- 「重啟快捷鍵」：重新檢查設定與兩項權限，重新建立快捷鍵監聽。校正中點擊會延後執行，多次點擊合併為一次。
- 「取消目前校正」：只在校正中顯示。
- 「查看錯誤詳情…」：只在發生錯誤後顯示，下一次校正開始後移除。
- 「使用說明」與「結束」。

### 怎麼排錯

1. 打開「檢查與測試…」，先看四項狀態。金鑰欄位是否已設定不代表金鑰一定有效。
2. 按「測試 Gemini」。App 只傳送固定句「這個輸入法的選自不太準，請幫我檢查錯自。」，使用自己的 API 配額，不讀取或替換文件，也不加入校正歷史。連線成功但結果未符合完整測試句時會另外說明。
3. 按「開始 30 秒檢查」，回到原 App 的文字欄位，選取文字並連按兩下右側 Option。浮動提示不會取得鍵盤焦點，會顯示收到按鍵、取得文字、等待 Gemini、檢查結果與替換，或說明沒開始的原因，例如欄位不支援、超過打字後 2 秒。
4. 檢查模式會在 30 秒後自動停止。重新打開「檢查與測試…」查看步驟；需要協助時，按「複製診斷報告」貼給協助者。報告不包含金鑰、原文或校正結果，僅包含版本、安裝位置、狀態與最近 50 個步驟。

在不支援的欄位或不符合觸發條件時，平常不會彈出提示。這些原因會出現在診斷步驟；只有實際開始處理的文字才加入校正歷史。檢查模式不記錄輸入按鍵內容。v2.4.0 與較舊版本仍使用原選單。

## 測試方式

在 TextEdit 的純文字文件中貼入三段：

```text
第一段保持不變。
這個輸入法的選自不太準，請幫我檢查錯自。
第三段也保持不變。
```

1. 選取第二段，連按兩下右側 Option。應只修正「選字」「錯字」，其他段落保持原樣。查看 spinner、勾號與回到「校」的過程，按 `⌘Z` 應可復原。
2. 取消選取，在第二段打幾個字，2 秒內連按兩下右側 Option。應校正目前段落。
3. 打字後等超過 2 秒，沒有選取文字時再按，應不觸發。
4. 在沒有文字游標的地方按，或連按左側 Option，應不觸發。
5. 校正等待中繼續打字，應保留新輸入並取消校正。
6. 結束並重新開啟 App，再校正一次，應保留原有金鑰設定。

v2.3.0 起可再確認浮動提示與排版行為：

- 校正等待時，文字末端旁應出現 spinner 與「校正中」。完成或取消後消失，文件不含任何提示字元。
- 選取「今天用ChatGPT整理了3份資料明天再檢查一次」並觸發，預期整理為「今天用 ChatGPT 整理了 3 份資料，明天再檢查一次。」。斷句仍可能隨模型結果不同。
- 選取「下載速度是10Gbps容量有20TB提升15%角度90°」，確認常見單位間距，以及 `15%`、`90°` 保持相連。數值應相同。
- 在中文中加入網址、版本號、行內程式碼或 Markdown 連結，確認受保護內容保持原樣。再選取含中文註解的 Markdown 程式碼區塊，確認程式碼列保持原文。
- 短標題與片語不應被強制補句號。聊天中的重複驚嘆號、問號與刪節號應保留語氣。結果不合預期時可按 `⌘Z` 復原。

接著逐一選取「三種用途」的輸入範例並觸發校正，應得到同一句預期結果。再測試 `我喜歡喝咖啡。` 的按鍵 `ji3vu3cj0 ck d8 zo >`，以及一般英文、網址、程式碼，確認還原與原文保留的行為。

部分 App 的文字欄位可能無法讀取或替換，請先用 TextEdit 確認。遇到問題時，回報使用的 App、操作步驟與選單中的錯誤訊息即可，請勿附上金鑰或私人文字。v2.4.0 起可點「查看錯誤詳情…」，v2.3.1 下載版可點「查看最近狀態…」。
